# Archie

Инструмент для работы с личным архивом публично доступных материалов и отдельными сценариями экспорта.

## Модули

- [Локальный архиватор](backup_tool/local/README.md) — сохраняет публично доступные главы в локальные TXT-файлы.
- [Облачный архиватор](backup_tool/cloud/README.md) — локальный архиватор с резервной копией в Dropbox.
- [Загрузчик на RanobeLib](backup_tool/ranobelib/README.md) — загружает главы из локального архива на RanobeLib с предварительным просмотром, безопасным хранением токена в переменной окружения и возобновлением после ошибок.

## Важно

Перед публикацией на сторонней платформе проверь права на размещение произведения и данные тайтла, ветки и команды. Модуль RanobeLib по умолчанию работает в режиме предварительного просмотра и не отправляет главы, пока явно не указан флаг `--publish`.

Архиватор работает только с обычными публично доступными страницами и не обходит авторизацию, платный доступ, CAPTCHA, DRM или другие технические ограничения.
