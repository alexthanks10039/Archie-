# Archie → RanobeLib uploader

Отдельный модуль для загрузки глав из локального архива Archie на RanobeLib. Не связан с Dropbox и не меняет локальный архив.

## Перед запуском

1. Убедись, что у тебя есть права на публикацию этого произведения.
2. Узнай ID тайтла (manga_id), ID ветки перевода (branch_id) и ID команды/переводчика (teams) на RanobeLib. Они не взаимозаменяемы.
3. Установи Python 3.10+.
4. Открой PowerShell в этой папке и установи зависимость:

   ```powershell
   python -m pip install -r requirements.txt
   ```

5. Передай access token через переменную окружения. Не вставляй токен в код и не отправляй его в GitHub.

   Для текущего окна PowerShell:

   ```powershell
   $env:RANOBELIB_ACCESS_TOKEN = "твой_access_token"
   ```

## Сначала тестовый просмотр

По умолчанию модуль работает в безопасном режиме: ничего не публикует.

Пример для глав 1590–1592:

```powershell
python uploader.py --input ..\local\backup\chapters --start 1590 --end 1592 --manga-id 123 --branch-id 456 --teams 789 --volume 1
```

Замени 123, 456, 789 на реальные ID своего тайтла, ветки и команды. Проверь, что названия и тексты глав корректны.

## Загрузка

Когда проверил параметры, повтори команду с `--publish`:

```powershell
python uploader.py --input ..\local\backup\chapters --start 1590 --end 1592 --manga-id 123 --branch-id 456 --teams 789 --volume 1 --publish
```

Для большого диапазона сначала загрузи 1–3 главы и проверь их на сайте. Только после проверки запускай полный диапазон. По умолчанию между запросами пауза 2 секунды.

## Названия и тома

- По умолчанию название создаётся как `Глава N`.
- Чтобы использовать первую строку локального файла как название, добавь `--use-source-title`.
- `--name-template "Глава {number} — {source_title}"` позволяет настроить шаблон.
- `--volume` задаёт номер тома для всех глав текущего запуска. Если главы принадлежат разным томам, загружай диапазоны отдельными запусками.

## Возобновление

Состояние хранится в `upload_state.json`. Успешные главы повторно не загружаются. Ошибочные главы по умолчанию пропускаются; для повторной попытки добавь `--retry-failed`.

Не удаляй и не редактируй `upload_state.json`, пока не проверишь результаты на RanobeLib. Состояние локальное и не содержит access token.

## Ограничения

Загрузчик использует стороннюю неофициальную библиотеку `ranobelib-loader`; API RanobeLib может измениться. Перед массовой загрузкой обязательно проверь тестовую главу вручную. Модуль не пытается обходить авторизацию или ограничения сайта.
