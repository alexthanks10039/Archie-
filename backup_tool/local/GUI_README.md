# Archie Windows GUI

Визуальный интерфейс для локального скачивания глав iFreedom через авторизованный Chromium.

## Установка

Запусти:

    install.bat

Скрипт установит зависимости проекта, Playwright и Chromium.

## Запуск

Запусти:

    start_gui.bat

В окне Archie:

1. Укажи диапазон глав.
2. Нажми «Запустить скачивание».
3. Откроется Chromium с отдельным профилем.
4. Войди в iFreedom вручную через обычное окно выбранного браузера. По умолчанию используется Яндекс Браузер.
5. Открой книгу и проверь, что текст доступен.
6. Нажми «Я вошёл в iFreedom» в окне Archie.
7. Смотри прогресс и ошибки в журнале.

Для первой проверки удобно нажать «Тест 1 главы».

## Где находятся файлы

Архив:

    backup\chapters\N.txt

Общий файл:

    backup\backup.txt

Состояние и ошибки:

    backup\manifest.json

Профиль браузера:

    .browser-profile\

Профиль содержит cookies/local storage авторизованной сессии и не должен попадать в Git.

## EXE

Для сборки:

    build_exe.bat

Результат:

    dist\Archie\Archie.exe

Playwright здесь используется для подключения к уже запущенному Chromium-совместимому браузеру через CDP; отдельный Chromium Archie не устанавливает.

## Ограничения

Программа не обходить CAPTCHA, платный доступ, DRM и другие технические ограничения. Авторизация выполняется пользователем вручную.
